Model

AlignAtt lookahead, in 0.02 s frames. Lower commits text sooner but revises more. 25 ≈ 500 ms.

Translation

Dual-pane forces every pair through NLLB, so both directions get the sentence-gate delay.

Much faster for FR→EN — no second model, no sentence gate. But it replaces the French text rather than adding English, and it is a server flag, so switching direction reloads the model. Unverified: leave off until Phase 0 confirms behaviour.

Only tick this once the mixed-paths spike profile has proven it. It removes the reload on direction change.

Reset

Set up the transcription engine

WhisperLive needs a private Python environment with CUDA PyTorch. It is about 4 GB and lives in this app's own folder — your system Python, if you have one, is not touched. This runs once.

Keep the machine awake and on a connection you do not pay by the gigabyte. You can close this panel; setup keeps running.
